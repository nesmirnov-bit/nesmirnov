1. В простейшем смысле, репозиторий  — это хранилище для данных и их истории изменений. В контексте разработки программного обеспечения это почти всегда означает хранилище для исходного кода проекта, его документации и других связанных файлов
2. Ключевые особенности репозитория . Хранение истории изменений: Репозиторий сохраняет не только последнюю версию файлов, а всю историю их изменений — кто, когда и какую правку внес.Можно создавать "ветки" — изолированные копии кода для разработки новой функциональности или исправления ошибок, не затрагивая основную версию.
3. Что такое команда разработки . Project Manager Отвечает за процесс "как" и "когда". Устраняет препятствия, следит за сроками и эффективностью работы команды. Backend-разработчики: Создают "мозг" приложения — серверную логику, базы данных.  Frontend-разработчики: Создают "лицо" приложения — то, что видит пользователь в браузере. Тестировщики - Гарантируют качество. Проверяют, что продукт работает как задумано, ищут ошибки и уязвимости.
4.  Связи внутри команды разработки и с репозиторием. Непрерывная коммуникация: Постоянный обмен информацией между аналитиками/дизайнерами и разработчиками для уточнения деталей, между разработчиками и тестировщиками для понимания критериев качества.
3. Взаимопомощь и код-ревью: Разработчики проверяют код друг друга перед слиянием в основную ветку. Это обеспечивает качество, распространение знаний и выявление ошибок на раннем этапе.
